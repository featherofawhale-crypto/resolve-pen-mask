钢笔与形状预设

预设写入原生钢笔路径；顶点、手柄和形状关键帧可以继续编辑。

GET STARTED

安装与使用

  1. 双击安装模板下载 PenMask.drfx，双击后在 Resolve 中确认安装。效果库只有「原生蒙版工具 → 钢笔蒙版」一个入口。
  2. 使用预设或自由绘制在检查器「形状预设」选择形状并点击「应用所选预设」；自由绘制时打开监看器的「Fusion 叠加」，选择「钢笔路径」绘制闭合路径。
  3. 切换到蒙版结果自由绘制完成后手动取消「显示原片（绘制时开启）」；预设应用后会自动取消。路径内保留画面，路径外透明。
GOOD TO KNOW

公开版的范围

八种预设都在同一个效果的检查器里。圆形、矩形、圆角矩形、三角形、菱形、五角星、五边形、六边形均写入可继续编辑的原生钢笔路径。

本独立包不含关键帧浮动面板、智能抠像和独立遮罩导出；原生形状关键帧仍保留。已有调色页智能抠像跟踪的片段，建议先阅读 GitHub README 的处理顺序说明。
