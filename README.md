# 钢笔蒙版 · Pen Mask

免费的 DaVinci Resolve 原生 Fusion 蒙版模板。在剪辑页把效果拖到视频片段，然后在同一个效果的检查器里选择形状预设，或用钢笔圈出需要保留的画面。支持羽化、反相、位置、大小和扩展功能。

**v0.2.0 公开预览版。**已在 macOS / Resolve Studio 19.1.4.11 的独立测试工程验证部分检查器预设。[下载安装包](https://qhxmp.cc/plugins/pen-mask/download/PenMask.drfx)。

## 安装与使用

1. 下载 `PenMask.drfx`，双击并在 Resolve 中确认安装。
2. 在 **效果库 → 效果 → 原生蒙版工具** 找到唯一的「钢笔蒙版」，拖到有图像输入的视频片段；列表未刷新时重启 Resolve。
3. 使用预设：在检查器 **特效 → Fusion → 钢笔蒙版 → Controls** 中，用 **形状预设** 下拉框选择圆形、矩形、圆角矩形、三角形、菱形、五角星、五边形或六边形，点击 **应用所选预设**。这会在当前帧写入原生钢笔路径，并自动取消“显示原片”。下拉框是要应用的形状选择器，不会随着撤销自动改名。
4. 自由绘制：打开剪辑页监看器的 **Fusion 叠加**，在检查器选择 **钢笔路径**，绘制并闭合路径。绘制时保持 **显示原片（绘制时开启）** 勾选；完成后手动取消。路径内显示画面，路径外透明；需要相反区域时开启 **反相**。
5. 预设生成后仍可改原生钢笔顶点、手柄和形状关键帧。在检查器调整 **中心、缩放、羽化、局部亮度、扩展功能**。扩展功能按像素输入：正值扩大蒙版，负值收缩，0 为原始边界；它使用原生 Erode/Dilate 节点。

预设都在同一个钢笔蒙版效果的检查器中；应用时覆盖该实例当前帧的钢笔形状，不修改其他片段的实例。圆形、多边形和五角星按当前合成画幅宽高生成；所有预设最终都是可编辑的原生钢笔路径。

也可以在 Fusion 页导入 `钢笔蒙版.setting`，将 `QinghePenMask` 组接在图像输入与 MediaOut 之间。

### 已在调色页完成智能抠像时

**不要把这个 Fusion 效果直接拖到同一个已跟踪片段上。** Resolve 会先计算剪辑页的 Fusion 效果，再将结果送入调色页。钢笔效果改变了智能抠像的输入，Resolve 19 可能使原有跟踪缓存失效；即使钢笔效果暂时处于“显示原片”状态，也不能保证跟踪数据被保留。这是宿主的处理顺序限制，模板内部调整节点无法改变。

如果刚拖入且发现跟踪消失，先撤销这次添加，再到调色页检查选区和跟踪状态。不要清空智能抠像节点或删除缓存；若撤销后仍未恢复，先保存工程副本，再从此前工程备份恢复或重新分析。不要把“画面暂时未显示遮罩”等同于原始笔画已被删除。

要继续用剪辑页钢笔效果，稳妥的流程是在**开始智能抠像前**先建立复合片段：进入复合片段，在内层原素材的调色页完成智能抠像；返回外层时间线，把钢笔效果拖到复合片段上。这样内层跟踪的输入不会随外层钢笔效果改变。对**已经跟踪完成**的片段临时创建复合片段，Resolve 19 是否保留现有跟踪须先在复制的工程中验证，不能直接在唯一工程上批量处理。若必须保持同一片段且不封装，应在调色页智能抠像节点之后使用调色页原生窗口，而不是此剪辑页 Fusion 模板。

## 这次公开的范围

包含原生钢笔蒙版、8 个形状预设和扩展功能的节点源码。关键帧浮动面板尚未完成，检查器没有启动面板的按钮。原生形状关键帧保留。

不包含 Electron 应用、Python 运行时、Lua 启动脚本、智能抠像、独立遮罩导出或自动跟踪。安装和运行这个模板无需额外依赖；Python 仅供开发者重新打包使用。

## 兼容与验证

- 钢笔基础节点在 **macOS / Resolve Studio 19.1.4.11** 的剪辑页已有绘制、闭合、手柄、撤销 / 重做、形状动画、保存与重开记录。
- 本地包已通过离线封装检查，并在独立剪辑页工程中验证：效果库仅一个入口、检查器显示 8 种预设、按钮应用圆形／矩形／五角星后画面按形状剪切、形状写入可撤销。其余预设、扩展正负值及长时间稳定性仍待逐项回归。
- Windows、Linux、Resolve 免费版及其他 Resolve 版本尚未完整实测；不把原生节点方案等同于已验证的全平台兼容。
- 绘制后需要手动关闭“显示原片”。暂未完成透明 / 预乘 Alpha 的逐像素验收和长期稳定性测试。

如果使用中遇到问题，请在 [Issues](https://github.com/featherofawhale-crypto/resolve-pen-mask/issues) 说明 Resolve 版本、系统和复现步骤。

## 开发

`钢笔蒙版.setting` 是完整可编辑的源码。用 Python 3 标准库重建并检查：

```sh
python3 build.py
python3 -m unittest -v test_package.py
```

`PenMask.drfx` 是确定性 ZIP，仅包含 `Edit/Effects/原生蒙版工具/钢笔蒙版.setting`。`preset_button.lua` 是固定的检查器预设生成脚本，由 `build.py` 嵌入模板。旧版 8 个效果库条目保存在 `validation/retired-effect-library-presets/`，不再打包。`SHA256SUMS.txt` 可用于核对安装包。
